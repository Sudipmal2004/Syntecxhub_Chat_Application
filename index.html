Everything a modern chat needs

A complete full-stack project: secure auth, REST API, real-time events and a polished interface.

  • Instant delivery

    Messages are saved to MongoDB and pushed over WebSockets with delivered and read receipts.

  • Private conversations

    Search any registered user and start a one-to-one chat in a single click.

  • Group rooms

    Create public or private rooms, join or leave in real time, and manage members.

  • Live presence

    Online and offline status with last-seen times, plus animated typing indicators.

  • Persistent history

    Every conversation is stored and loaded with cursor-based pagination for fast scrolling.

  • Secure by design

    bcrypt hashing, JWT sessions, rate limiting, validation and a strict content security policy.
